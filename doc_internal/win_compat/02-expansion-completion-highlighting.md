# Expansion, command discovery, completion, and highlighting

## Verified N3 implementation

Native command substitution now follows the shared expansion order and separated-element rules,
including nested functions/blocks and bounded output. Genuine deferred-buffer retention faults
abort the affected expansion without mistaking native exit 122 for an I/O failure.
Declarative completion/abbreviation storage and batch syntax colorization are implemented.
This is not active Tab completion, suggestions or editor abbreviation expansion: those remain N7.
See [N3 evidence and option mapping](coverage.md#n3-verified-evidence-record).

## Historical scope and evidence

Source-grounded component mappings follow; none is a claim of an exercised Windows port. The [coverage ledger](coverage.md) inventories source files; [07](07-filesystem-paths-wildcards.md) covers underlying path/directory operations, [09](09-history-functions-autoload.md) covers autoload state, and [13](13-binaries-and-assets.md) covers the executable fish-script/Python assets that the engine loads.

## Highlighting and autosuggestion validation

[`highlight/mod.rs`](../../src/highlight/mod.rs) declares the implementation and file-tester children and reexports highlighting symbols. It has no native Linux functionality and needs no Windows API replacement; its children below own the portability boundaries.

| Component and concrete evidence | Linux/POSIX dependency, or none | Native Windows mapping and gaps | Proposed validation |
|---|---|---|---|
| [Syntax/color roles](../../src/highlight/highlight.rs): `highlight_shell`, `HighlightSpec`, `HighlightColorResolver`, `colorize` | AST traversal, role assignment and color selection are portable. `colorize` uses the terminal output service, so ANSI emission/capabilities are a separate dependency. | Reuse roles/theme variables; render through the terminal backend rather than console APIs embedded in the highlighter. | Unfinished code, nested quotes/substitutions, dark/light theme changes, no-color terminals and ANSI/HTML formatter output. |
| [Command classification and history validation](../../src/highlight/highlight.rs): `autosuggest_validate_from_history`, `autosuggest_parse_command`, `is_veritable_cd` | Builtin/function checks are in-memory; executable lookup, required-path existence and `CDPATH`/same-directory checks use filesystem services. Function checks deliberately use `exists_no_autoload`. | Shared command/path/identity service; do not execute or autoload arbitrary functions to color a token. | Stale history paths, removed executable, overridden `cd`, changed `CDPATH`, same-directory aliases/junctions and cancelled background work. |
| [Path/redirection prediction](../../src/highlight/file_tester.rs): `FileTester::test_path`, `test_cd_path`, `test_redirection_target`, `is_potential_path` | `PATH_MAX` heuristics, `wstat`, `waccess(R_OK/W_OK)`, `ENOENT`, slash suffixes, and parent-directory permission checks. fd targets are parsed numerically, not probed as file handles. | ACLs, sharing violations, reserved device names and native long paths differ from mode bits. Non-destructive metadata/access queries can only predict; do not create/truncate a file on each keystroke. Keep actual opens authoritative. | Writable-looking but ACL-denied target, read-only attribute, sharing denial, missing parent, no-clobber existing target, long/non-BMP path and invalid numeric fd target. |
| [Case sensitivity](../../src/highlight/file_tester.rs): `fs_is_case_insensitive` | Apple code queries `fpathconf(_PC_CASE_SENSITIVE)`; non-Apple implementation does not establish Windows directory semantics. | NTFS can be case-sensitive per directory; network filesystems can differ. Preserve actual spelling and filesystem results rather than globally lowercasing names. | Two files differing only by case in an enabled directory, case-preserving completion, and UNC shares with different sensitivity. |
| [Cancellation/context](../../src/operation_context.rs): `get_bg_context`, generation counts, expansion limits | Generation callbacks are portable; interruptible contexts also poll Unix signal cancellation. | Retain generation cancellation and adapt signal checks to the native cancellation service. ## Classification and limits

Matching, ranking and syntax/color roles are **portable logic**. Accounts, executable search, filesystem traversal/identity, permissions and process-backed completion cross **host-backed boundaries**. The original proposed scenarios were not execution evidence; the N1/N3 records delimit actual support. Full programmable editor completion and shipped helper breadth remain N7/N9, not implied by stored declarations or batch highlighting.
